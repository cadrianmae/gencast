What unlocks the long-podcast capability

Stage 6: per-segment loop
Each segment gets its own 5K-token output budget. 10 segments = ~50K total dialogue tokens = 30-60 min audio. Removes the structural ~20-min ceiling.
Stage 4: map-reduce compression
For 100K+ source tokens: chunk → summarize each → recurse until fits. Frees output budget for the per-segment dialogue calls.
Anthropic prompt caching
Per-segment shape lets the constant prefix (briefing + content + outline) be cached. ~70% input-token savings across segments 2-N.
Stage 9: native timing
Audio combination knows each clip's start/end ms — emits SRT directly without a Whisper post-pass. Saves a buck per podcast.
